# Motor de Busca para Licitações Públicas

Projeto acadêmico desenvolvido na disciplina de Engenharia de Software.

## 📌 Sobre o Projeto

O sistema proposto consiste em uma plataforma SaaS para prospecção ativa e inteligente de licitações públicas.

O objetivo é automatizar e otimizar a busca de oportunidades em editais publicados no PNCP (Portal Nacional de Contratações Públicas), permitindo que fornecedores encontrem licitações relevantes de forma rápida, personalizada e eficiente.

---

## 🎯 Problema

Atualmente, fornecedores enfrentam dificuldades para acompanhar o grande volume de editais publicados diariamente no PNCP.

Os principais problemas identificados são:

- Excesso de editais publicados diariamente
- Filtros pouco inteligentes
- Processo manual e demorado
- Perda de oportunidades por dificuldade de monitoramento

---

## 💡 Solução

O sistema atuará como um motor de busca inteligente para licitações públicas, permitindo:

- Filtragem por palavra-chave
- Busca por estado (UF)
- Segmentação personalizada
- Alertas automáticos
- Monitoramento de prazos
- Organização das oportunidades encontradas
